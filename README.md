# 电子书阅读器 PWA

一个基于epub.js的纯前端电子书阅读器应用，支持PWA功能。

## 功能特点

- 支持EPUB格式电子书
- 简洁的用户界面
- 键盘导航支持（左右箭头键翻页）
- 响应式设计
- PWA支持（可安装到桌面）
- 离线缓存功能
- 书签功能
- 目录导航
- 标记功能

## 使用方法

### 本地运行
1. 使用任何HTTP服务器（如Live Server、Python SimpleHTTPServer等）
2. 或直接在浏览器中打开index.html（部分功能可能受限）

### 在线部署
1. 上传到GitHub Pages、Netlify、Vercel等静态托管服务
2. 自动获得HTTPS和完整PWA功能

## 操作说明

- **加载电子书**：选择EPUB文件后点击按钮
- **上一页**：点击按钮或按左箭头键
- **下一页**：点击按钮或按右箭头键
- **书签**：右上角下拉添加书签
- **目录**：点击菜单查看目录
- **标记**：添加和管理阅读标记

## 技术栈

- epub.js - 电子书解析和渲染
- HTML5/CSS3 - 用户界面
- IndexedDB - 本地数据存储
- Service Worker - PWA缓存

## 文件结构

```
├── index.html      # 主页面
├── db.js          # 数据库管理
├── sw.js          # Service Worker
├── manifest.json  # PWA配置
├── icons/         # 应用图标
└── README.md      # 说明文档
```

## PWA功能

- **可安装**：支持安装到桌面，像原生应用一样使用
- **离线缓存**：核心文件会被缓存，支持离线访问
- **响应式**：适配各种设备屏幕
- **快速加载**：Service Worker提供快速缓存访问
- **本地存储**：书签、设置等数据本地保存
